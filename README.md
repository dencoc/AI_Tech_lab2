# Лабораторная работа №2

## Постановка задачи

Разработать веб-приложение на Django для магазина товаров для быта.

В рамках индивидуального варианта необходимо реализовать:

* учет товаров магазина;
* учет покупателей;
* оформление покупок;
* накопительную систему скидок;
* расчет размера скидки в зависимости от количества совершенных покупок любых товаров;
* отображение итоговой стоимости товара с учетом скидки.

Для накопительной скидки используется следующая система:

| Количество покупок | Скидка |
| -----------------: | -----: |
|                0–4 |     0% |
|                5–9 |     5% |
|              10–19 |    10% |
|         20 и более |    15% |

## Краткое описание проекта

Проект представляет собой веб-приложение интернет-магазина товаров для быта, разработанное с использованием Django.

В приложении реализованы три основные сущности:

* **Product** — товар, содержащий название и цену;
* **Customer** — покупатель, содержащий имя и адрес;
* **Purchase** — покупка, связывающая покупателя с приобретенным товаром и содержащая дату покупки.

На главной странице отображается список доступных товаров с указанием их названия и стоимости.

При выборе товара пользователь переходит на страницу оформления покупки, где указывает имя и адрес покупателя. Если покупатель уже совершал покупки, он определяется по указанным данным и получает накопительную скидку в соответствии с количеством предыдущих покупок.

После оформления покупки приложение рассчитывает размер скидки и итоговую стоимость товара.

Количество покупок покупателя определяется по связанным объектам `Purchase`, поэтому покупки любых товаров учитываются в общей накопительной системе.

## Реализованные модели

### Product

Модель товара содержит:

* `name` — название товара;
* `price` — цена товара.

### Customer

Модель покупателя содержит:

* `name` — имя покупателя;
* `address` — адрес покупателя.

Для модели реализованы методы:

* `get_purchase_count()` — определение количества совершенных покупок;
* `get_discount()` — определение текущего размера накопительной скидки.

### Purchase

Модель покупки содержит:

* `product` — приобретенный товар;
* `customer` — покупатель;
* `date` — дата и время покупки.
